\# QuizMaster - Smart Online Quiz Platform



A full-stack MERN application built as the Final Capstone Project for WsCube Tech Full Stack Development Mentorship Program (Cohort 06).



\## Live Demo

\- Frontend: https://quizmaster-1-ihok.onrender.com

\- Backend API: https://quizmaster-o36d.onrender.com



\## Features

\- User registration and login with JWT authentication

\- Admin panel to create and manage quizzes

\- Users can take quizzes and view scores

\- Dashboard showing quiz attempt history

\- Role-based access (Admin \& User)

\- Secure password hashing with bcrypt



\## Tech Stack

\- Frontend: React.js, React Router DOM, Axios, Context API

\- Backend: Node.js, Express.js

\- Database: MongoDB Atlas

\- Authentication: JWT (JSON Web Tokens)

\- Password Hashing: bcrypt

\- Deployment: Render (Frontend + Backend), MongoDB Atlas
